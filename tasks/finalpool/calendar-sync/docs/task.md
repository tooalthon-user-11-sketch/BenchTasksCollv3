# Calendar Sync Task

## Overview
Develop a calendar synchronization system that keeps calendars in sync across multiple platforms.

## Requirements

### Core Features
1. **Calendar Integration**: Integrate with various calendar platforms.
2. **Event Sync**: Synchronize events across calendars in real-time.
3. **Conflict Detection**: Detect and resolve scheduling conflicts.
4. **Event Management**: Create, edit, and delete events across calendars.
5. **Reminders**: Set and manage reminders for events.
6. **Analytics**: Provide analytics on scheduling patterns.
7. **Data Persistence**: Store synchronization configurations and history.

## Evaluation Criteria
- All core features are implemented and functional
- Synchronization is accurate and real-time
- Conflict detection is effective
- Event management works across platforms
- Analytics are informative

## Example Workflow
1. User connects multiple calendars
2. Events are synchronized across calendars
3. Conflicts are detected and resolved
4. Reminders are set for events
5. Analytics track scheduling patterns
