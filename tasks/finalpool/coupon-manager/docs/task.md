# Coupon Manager Task

## Overview
Develop a coupon management system for creating, distributing, and tracking coupons and discounts.

## Requirements

### Core Features
1. **Coupon Creation**: Create coupons with discount type, value, expiration, and usage limits.
2. **Coupon Distribution**: Distribute coupons through various channels.
3. **Coupon Redemption**: Track and process coupon redemptions.
4. **Analytics**: Provide analytics on coupon performance and usage.
5. **Integration**: Integrate with e-commerce and POS systems.
6. **Fraud Prevention**: Detect and prevent coupon fraud.
7. **Data Persistence**: Store coupon data in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Coupons are created and distributed correctly
- Redemption tracking is accurate
- Analytics are comprehensive
- Fraud prevention is effective

## Example Workflow
1. User creates a new coupon
2. Coupon is distributed to customers
3. Customers redeem coupons
4. System tracks redemptions and generates analytics
