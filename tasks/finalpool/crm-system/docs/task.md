# CRM System Task

## Overview
Develop a Customer Relationship Management (CRM) system for managing customer interactions and sales.

## Requirements

### Core Features
1. **Contact Management**: Manage customer contacts and interactions.
2. **Deal Tracking**: Track and manage sales deals and opportunities.
3. **Task Management**: Create and manage tasks related to customer interactions.
4. **Reporting**: Generate reports on customer relationships and sales performance.
5. **Automation**: Automate repetitive CRM tasks and workflows.
6. **Integration**: Integrate with other business systems and tools.
7. **Data Persistence**: Store CRM data in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Contact management is comprehensive
- Deal tracking is accurate
- Task management is intuitive
- Reports are informative and actionable

## Example Workflow
1. User adds a new customer contact
2. User creates a deal for the customer
3. Deal progresses through sales stages
4. User generates a sales report
5. System automates follow-up tasks
