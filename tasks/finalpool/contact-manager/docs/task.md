# Contact Manager Task

## Overview
Develop a contact management system for organizing and managing contact information.

## Requirements

### Core Features
1. **Contact Creation**: Add new contacts with name, email, phone, and company.
2. **Contact Management**: View, edit, and delete contacts.
3. **Contact Organization**: Organize contacts into groups, tags, and categories.
4. **Contact Search**: Search for contacts by various criteria.
5. **Contact Import/Export**: Import and export contacts from various sources.
6. **Duplicate Detection**: Detect and merge duplicate contacts.
7. **Data Persistence**: Store contact data in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Contacts are created and managed correctly
- Organization features are intuitive
- Search functionality is effective
- Import/Export works reliably

## Example Workflow
1. User adds a new contact
2. Contact is organized into groups
3. User searches for contacts
4. User exports contacts to CSV
