# Media Organizer Task

## Overview
Develop a media organization system for managing and organizing media files.

## Requirements

### Core Features
1. **Media Analysis**: Analyze media files for content and metadata.
2. **Media Organization**: Organize media files into folders, categories, and tags.
3. **Media Search**: Search for media files by content, metadata, or tags.
4. **Media Processing**: Process media files (resize, convert, enhance).
5. **Media Library**: Manage a centralized media library.
6. **Media Sharing**: Share media files with other users or systems.
7. **Data Persistence**: Store media metadata and organization.

## Evaluation Criteria
- All core features are implemented and functional
- Media is analyzed accurately
- Organization is intuitive and effective
- Search is fast and accurate
- Processing maintains quality

## Example Workflow
1. User uploads media files
2. System analyzes and organizes media
3. User searches for specific media
4. System processes media as needed
5. Media is shared or exported
