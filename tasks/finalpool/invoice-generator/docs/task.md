# Invoice Generator Task

## Overview
Develop an invoice generation system for creating, managing, and tracking invoices.

## Requirements

### Core Features
1. **Invoice Creation**: Create invoices with client, items, amounts, and due dates.
2. **Invoice Management**: View, edit, and delete invoices.
3. **Payment Tracking**: Track payment status and send reminders.
4. **Reporting**: Generate reports on invoicing and payments.
5. **Integration**: Integrate with accounting and payment systems.
6. **Automation**: Automate invoice generation and payment reminders.
7. **Data Persistence**: Store invoice data in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Invoices are created and managed correctly
- Payment tracking is accurate
- Reports are comprehensive
- Automation works reliably

## Example Workflow
1. User creates a new invoice
2. Invoice is sent to client
3. Payment is tracked
4. Reports are generated
