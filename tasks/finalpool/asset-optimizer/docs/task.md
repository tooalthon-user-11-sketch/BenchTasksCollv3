# Asset Optimizer Task

## Overview
Develop an asset optimization system for optimizing digital assets for web and mobile applications.

## Requirements

### Core Features
1. **Image Optimization**: Optimize images for web (resize, compress, convert formats).
2. **Asset Analysis**: Analyze assets for size, format, and quality.
3. **Batch Processing**: Process multiple assets in a single operation.
4. **CDN Integration**: Integrate with Content Delivery Networks (CDNs).
5. **Performance Monitoring**: Monitor asset performance and loading times.
6. **Reporting**: Generate reports on asset optimization and savings.
7. **Data Persistence**: Store optimization configurations and results.

## Evaluation Criteria
- All core features are implemented and functional
- Image optimization is effective
- Batch processing is efficient
- CDN integration works correctly
- Performance monitoring is accurate

## Example Workflow
1. User uploads assets for optimization
2. System analyzes and optimizes assets
3. Optimized assets are delivered via CDN
4. Performance is monitored and reported
