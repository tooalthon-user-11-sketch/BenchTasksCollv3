# Data Analytics Task

## Overview
Develop a data analytics platform that provides insights through analysis, visualization, and reporting.

## Requirements

### Core Features
1. **Data Analysis**: Analyze datasets to identify trends, patterns, and insights.
2. **Visualization**: Create charts, graphs, and dashboards.
3. **Reporting**: Generate comprehensive reports with actionable insights.
4. **Predictive Analytics**: Perform predictive analysis to forecast trends.
5. **Data Preparation**: Clean and prepare data for analysis.
6. **Ad Hoc Queries**: Answer specific questions about the data.
7. **Data Persistence**: Store analysis results in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Analysis is accurate and insightful
- Visualizations are clear and informative
- Reports are comprehensive
- Predictive models are accurate

## Example Workflow
1. User uploads a dataset
2. System analyzes the data
3. System generates visualizations
4. User creates a report
5. System provides predictive insights
