# Data Validator Task

## Overview
Develop a data validation system that ensures data quality by validating against predefined rules and schemas.

## Requirements

### Core Features
1. **Data Validation**: Validate data against predefined rules and schemas.
2. **Error Detection**: Identify and report data quality issues.
3. **Data Cleaning**: Clean and normalize data to meet quality standards.
4. **Reporting**: Generate reports on data quality metrics.
5. **Rule Management**: Create and manage validation rules.
6. **Integration**: Integrate with various data sources and systems.
7. **Data Persistence**: Store validation results in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Data validation is accurate
- Error detection is comprehensive
- Data cleaning is effective
- Reports are informative

## Example Workflow
1. User uploads a dataset
2. System validates data against rules
3. System identifies and reports issues
4. System cleans and normalizes data
5. System generates a quality report
