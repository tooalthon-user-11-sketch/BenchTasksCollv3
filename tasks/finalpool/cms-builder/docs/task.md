# CMS Builder Task

## Overview
Develop a CMS builder that helps users set up and manage Content Management Systems.

## Requirements

### Core Features
1. **CMS Setup**: Set up and configure a CMS.
2. **Content Creation**: Create and manage content within the CMS.
3. **Theme Management**: Manage and customize CMS themes.
4. **Plugin Management**: Install and manage CMS plugins.
5. **User Management**: Manage user roles and permissions.
6. **SEO Optimization**: Optimize content for search engines.
7. **Data Persistence**: Store CMS configuration and content.

## Evaluation Criteria
- All core features are implemented and functional
- CMS setup is straightforward
- Content creation is intuitive
- Theme and plugin management works correctly
- User management is secure

## Example Workflow
1. User sets up a new CMS
2. User creates and manages content
3. User customizes themes and plugins
4. User manages user roles
5. System optimizes content for SEO
