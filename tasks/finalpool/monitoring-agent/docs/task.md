# Monitoring Agent Task

## Overview
Develop a monitoring agent that tracks system health, performance, and availability.

## Requirements

### Core Features
1. **System Monitoring**: Monitor system health, performance, and availability.
2. **Alerting**: Generate alerts for anomalies, failures, or performance issues.
3. **Dashboards**: Provide real-time dashboards for system metrics.
4. **Log Analysis**: Analyze system logs for issues and patterns.
5. **Incident Management**: Help manage and resolve incidents.
6. **Reporting**: Generate reports on system health and performance.
7. **Data Persistence**: Store monitoring data in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Monitoring is accurate and real-time
- Alerts are timely and actionable
- Dashboards are informative
- Log analysis is effective

## Example Workflow
1. Agent starts monitoring a system
2. System metrics are collected and analyzed
3. Alerts are generated for anomalies
4. Dashboard displays real-time metrics
5. Reports are generated for review
