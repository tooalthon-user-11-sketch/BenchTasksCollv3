# Backup Utility Task

## Overview
Develop a backup utility for creating, managing, and restoring backups of data and systems.

## Requirements

### Core Features
1. **Backup Creation**: Create backups of files, databases, and systems.
2. **Backup Scheduling**: Schedule automated backups at regular intervals.
3. **Backup Storage**: Store backups in secure locations (local, cloud, tape).
4. **Backup Restoration**: Restore data from backups when needed.
5. **Backup Verification**: Verify the integrity of backups.
6. **Backup Management**: Manage backup retention and cleanup.
7. **Data Persistence**: Store backup configurations and logs.

## Evaluation Criteria
- All core features are implemented and functional
- Backups are created and stored correctly
- Restoration works reliably
- Verification is accurate
- Scheduling is flexible

## Example Workflow
1. User creates a backup
2. Backup is stored securely
3. Backup is verified
4. User restores from backup when needed
