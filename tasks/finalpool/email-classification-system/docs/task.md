# Email Classification System Task

## Overview
Develop an email classification system that automatically categorizes and organizes emails.

## Requirements

### Core Features
1. **Email Ingestion**: Process incoming emails from various sources.
2. **Classification**: Automatically classify emails into predefined categories.
3. **Prioritization**: Identify and flag important or urgent emails.
4. **Summarization**: Generate concise summaries of email content.
5. **Action Suggestions**: Suggest appropriate actions for each email.
6. **Reporting**: Provide analytics on email patterns and trends.
7. **Data Persistence**: Store classified emails in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Emails are classified accurately
- Prioritization works correctly
- Summaries are concise and informative
- Action suggestions are appropriate

## Example Workflow
1. System ingests new emails
2. Emails are classified into categories
3. Important emails are flagged
4. Summaries are generated
5. Action suggestions are provided
