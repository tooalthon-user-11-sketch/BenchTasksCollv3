# Streaming Service Task

## Overview
Develop a streaming service for delivering video, audio, and live content to users.

## Requirements

### Core Features
1. **Content Management**: Manage streaming content (videos, audio, live streams).
2. **Content Delivery**: Deliver content to users via streaming protocols.
3. **User Management**: Manage user accounts, subscriptions, and preferences.
4. **Recommendation Engine**: Recommend content based on user preferences.
5. **Analytics**: Provide analytics on content performance and user engagement.
6. **Live Streaming**: Support live streaming and broadcasting.
7. **Data Persistence**: Store content metadata and user data.

## Evaluation Criteria
- All core features are implemented and functional
- Content is delivered smoothly
- User management is secure
- Recommendations are relevant
- Analytics are accurate

## Example Workflow
1. User browses content library
2. System recommends content
3. User starts streaming
4. Analytics track engagement
