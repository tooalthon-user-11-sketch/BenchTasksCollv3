# Content Manager Task

## Overview
Develop a content management system for creating, organizing, and publishing digital content.

## Requirements

### Core Features
1. **Content Creation**: Create new content (articles, blog posts, social media posts).
2. **Content Organization**: Organize content into categories, tags, and folders.
3. **Content Editing**: Edit and revise content.
4. **Content Publishing**: Publish content to various platforms.
5. **Content Archiving**: Archive old or unused content.
6. **Content Analytics**: Provide analytics on content performance.
7. **Data Persistence**: Store content in a structured format.

## Evaluation Criteria
- All core features are implemented and functional
- Content is created and organized correctly
- Editing functionality is intuitive
- Publishing works across platforms
- Analytics are accurate and informative

## Example Workflow
1. User creates a new blog post
2. Content is organized into categories
3. User edits and revises the content
4. Content is published to the blog
5. Analytics track performance
